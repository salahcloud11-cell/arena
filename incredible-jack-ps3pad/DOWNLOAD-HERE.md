The mod has a new signature. Uninstall the original Incredible Jack before installing this APK.
Uninstalling can remove local save data, so back it up first if the phone offers that option.

## Controller

The original Cocos2d-x launcher and native game libraries remain in place. Controller input is
converted into the same multi-touch events as the game's own on-screen controls.

- LEFT STICK defaults to the separate left/right touch buttons used by this platform game.
- RIGHT STICK, CROSS, CIRCLE, SQUARE, TRIANGLE, L1/R1, L2/R2, START/SELECT,
  L3/R3 and all D-pad directions are supported.
- Analog-only L2/R2 drivers are supported.
- Five additional screen buttons can be added.
- Every target has PLACE, CHANGE, and 1x–5x multi-click.

## Invisible touch targets

Target circles are **invisible by default** during gameplay. The controller remains active.
Use `SHOW TARGETS` only while checking positions, then choose `HIDE TARGETS` / `MAKE INVISIBLE`.
The visibility setting, positions, mappings and click counts are saved.
